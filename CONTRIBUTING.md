# Contributing

Thanks for your interest in the Lumen Charts trading platform.

## Pull requests

We are not accepting pull requests at the moment, so opening them is limited to
maintainers. This repository is published from the Lumen Charts development
repository, and each release arrives here as a single commit.

## Issues

Bug reports and feature ideas are welcome as
[issues](https://github.com/lumenchartshq/trading-platform/issues). For a bug,
include the package and chart versions and a small example that reproduces it.

## Building locally

```bash
pnpm install
pnpm build
pnpm typecheck
pnpm test
```

## Reporting security issues

Please do not open a public issue. Email oss@lumencharts.com instead.
